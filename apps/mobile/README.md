# Amiko Android

This folder contains the React Native Android app. It is separate from
`apps/android`, the earlier native phone-sign-in test harness. iOS development
belongs to a separate team and is not part of this folder's deliverable.

See [PROJECT.md](PROJECT.md) for current Sprint 5 scope, checks, and the
remaining integration work. The Android package is
`com.eldercaresaathi.amiko`.
